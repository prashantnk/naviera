# Verify Frontend Compliance Audit

Use this skill when modifying, adding, or refactoring React components, pages, or routing directories in the Next.js frontend.

## 🚀 Execution Workflow

To perform the compliance checks, navigate to the `frontend` folder and run the unified test command:

```bash
cd frontend
npm run test:audit
```

This runs a suite of audit scripts that analyze the codebase and write their results to the git-ignored `frontend/logs/` directory:

1.  **`logs/client_server_issues.log`**: Generated by `scripts/check-client-server.py`. Validates React Hook calls inside server components and flags missing `"use client"` directives or conflicting `"use server"` declarations.
2.  **`logs/math_results.log`**: Generated by `scripts/math-check.py`. Scans for mathematical operations (`*`, `/`, `+`) matching financial terms (tax, fees, cod) to enforce the **Zero Frontend Math** rule.
3.  **`logs/hardcoded_colors.log`**: Generated by `scripts/find-branding-colors.py`. Flags hardcoded Tailwind color classes (like `bg-blue-600`) to guarantee that components use dynamic CSS variable tokens (e.g. `bg-primary`) in compliance with the **Styling Engine**.
4.  **`logs/volumetric_results.log`**: Generated by `scripts/find-volumetric.py`. Validates that box dimensional limits are kept aligned.

## 🛠️ Resolving Failures

If the audit log files contain any reports:

*   **For styling violations:** Replace the hardcoded Tailwind color class with the theme-aware design tokens. E.g. replace `bg-indigo-600` or `text-blue-500` with `bg-primary` or `text-primary-foreground`.
*   **For math violations:** Refactor the calculation out of the React UI step. Ensure pricing details are read directly from the backend quotes API (`pricing_breakdown` payload).
*   **For React hook warnings:** Verify component boundaries and ensure `"use client"` is declared at the absolute top of the leaf components using state.
